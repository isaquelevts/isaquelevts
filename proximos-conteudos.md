## 3. As 10 ferramentas de SEO para ranquear no Google

**Referência:** reel de David Feldman (https://www.instagram.com/reel/Dc_-4BiJuDI/), 34 segundos, em inglês. Legenda: "Top 10 SEO tools. Comente 'SEO' e eu envio os links das 10 ferramentas de graça."

### Transcrição (original, em inglês)

O vídeo é um prompt falado para o Claude, no mesmo estilo do reel do "site lento". Os nomes de ferramentas foram corrigidos (a transcrição automática errou "Ubersuggest").

> Hey, Claude, I want to rank number one on Google, so please use Google Search Console to see what's already working. Pull the data from the keyword planner. Check all Google Trends for what's about to blow up. Answer the Public to see what people are actually searching for. Ubersuggest to find all the easy wins. Run Screaming Frog to fix what's broken on my site. PageSpeed Insights to make sure it's not slow. Rich Results Test so I show up as a snippet. Yoast to clean up all my pages. And Google Business Profile so I rank locally too. Lastly, make no mistakes. If you want all 10 URLs, comment SEO and I'll send it free.

### Tradução literal (em lista)

**Abertura**
- "Ei, Claude, eu quero ficar em primeiro lugar no Google."

**As 10 ferramentas**
1. Google Search Console, para ver o que já está funcionando
2. Planejador de palavras-chave, para puxar os dados
3. Google Trends, para ver o que está prestes a estourar
4. Answer the Public, para ver o que as pessoas realmente pesquisam
5. Ubersuggest, para achar as vitórias fáceis
6. Screaming Frog, para consertar o que está quebrado no site
7. PageSpeed Insights, para garantir que o site não esteja lento
8. Teste de Resultados Rich (Rich Results Test), para aparecer como destaque (snippet)
9. Yoast, para limpar todas as páginas
10. Perfil da Empresa no Google (Google Business Profile), para ranquear também localmente

**Fecho**
- "Por último, não cometa erros."
- "Se você quer os 10 links, comente SEO e eu envio de graça."

### Roteiro adaptado (texto próprio, ~35s)

**Abertura (0–4s)**
- "Se você quer aparecer em primeiro no Google, você precisa de 10 ferramentas:"

**Lista (fale em sequência, rápido)**
- Google Search Console: para ver o que já traz visitas
- Planejador de palavras-chave: para saber quanto cada busca rende
- Google Trends: para pegar o assunto antes de ele estourar
- Answer the Public: para ver as perguntas reais das pessoas
- Ubersuggest: para achar palavras fáceis de ranquear
- Screaming Frog: para achar link quebrado e erro no site
- PageSpeed Insights: para medir a velocidade
- Teste de Resultados Rich: para ver se o seu site pode aparecer em destaque
- Yoast: para organizar título e descrição de cada página
- Perfil da Empresa no Google: para aparecer no mapa e nas buscas da sua cidade

**Fecho (30–35s)**
- "Quer os links das 10? Comenta SEO que eu te mando no direct. Salva esse vídeo pra usar de checklist."

### Adaptação para o nicho de sites
- **Mostrar na tela:** cada ferramenta em 1–2 segundos, com o logotipo e o nome grande. Evite tela cheia de texto.
- **Para o público brasileiro:** destaque o Perfil da Empresa no Google (antigo "Google Meu Negócio") para negócios locais. É o item que mais gera cliente para quem vende para a própria cidade.
- **Ordem sugerida:** comece pelas ferramentas gratuitas do Google (1, 2, 3, 7, 8, 10) e deixe as de terceiros (4, 5, 6, 9) para depois. Isso passa a ideia de que dá para começar sem pagar.
- **Aviso na legenda:** Screaming Frog tem versão gratuita limitada, e Ubersuggest e Yoast têm versões pagas. Deixe isso claro para não frustrar quem seguir.
- **Isca de DM (quem comentar "SEO"):** envie a lista de links abaixo, com uma frase curta de como usar cada ferramenta.
- **Crédito:** considere marcar David Feldman como inspiração.

### Mensagem de DM com os links (confira os links antes de enviar)

```

3. Google Trends: https://trends.google.com.br
4. Answer the Public: https://answerthepublic.com
5. Ubersuggest: https://neilpatel.com/ubersuggest/

Dica: comece por 1, 7 e 10. São gratuitas e dão resultado mais rápido.
```

## Ideias para a série (para gravar depois)
- **Série "Se o seu site… você precisa…":** tema de cada vídeo = um problema (lento, sem aparecer no Google, sem clientes, com risco legal).
- **Série "Degraus do seu site":** escada de 5 degraus (título, topo da página, provas, páginas-chave, chamada para ação), inspirada no reel de Marcos Lacerda sobre perfil de Instagram.
- **Série "Cole no Claude":** cada vídeo termina com um prompt pronto para a pessoa colar e aplicar no próprio site.
